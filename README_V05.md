# Тривога — Симулятор v0.5.0

**Неофіційний застосунок. Не отримує реальних сповіщень і не замінює офіційні джерела.**

Код: https://github.com/tihomirovsmile/tryvoga-simulator

## Зміни

- Шість готових рофл-сценаріїв; останні чотири вилучено.
- Власні рофл-сценарії: назва, опис, зображення й MP3/OGG/WAV/M4A (необов'язково).
- Пошук областей, районів, громад і населених пунктів: локальний індекс, асинхронна фільтрація, лінивий список, обмеження до 180 збігів.
- Київ та аналогічні міста не підміняються «областю», коли існує єдиний відповідний населений пункт.
- Повітряна тривога — тільки район. Для хімічної, радіаційної небезпеки, вуличних боїв дозволено район або населений пункт; для артобстрілу й точкових загроз — населений пункт.
- «Оголосити по мапі» вилучено повністю.
- Мапа: тільки Україна, власний Canvas; райони/області з геоданих, локальний кеш Path, pinch-to-zoom. Час і журнал подій залишені на мапі.
- Банер фонду «Спільнота Стерненка», добровільний, з кнопкою приховування і вимикачем у налаштуваннях.
- Пояснення про незалежність проєкту та посилання на GitHub у «Корисне».

## AndroidIDE

1. Встановіть/налаштуйте JDK 17 та Android SDK. Якщо ToolingServer повідомляє «openjdk/bin/java: No such file or directory», спершу виконайте налаштування AndroidIDE (`idesetup -c`).
2. Розпакуйте архів. Відкрийте папку `TrivogaSimulator_AndroidIDE`, де лежить `settings.gradle.kts`.
3. Дочекайтеся завантаження Gradle 8.9 і залежностей.
4. Зберіть модуль `app` або запустіть `:app:assembleDebug`.

### Геометрія карти

Карта **не використовує OpenStreetMap SDK, сервер тайлів або геосервіс при масштабуванні**. Вона самостійно малює векторні полігони на `Canvas`.

- **GitHub Actions:** `scripts/prefetch_geojson.py` завантажує статичну геометрію, `scripts/compile_offline_map.py` спрощує її і записує в `app/src/main/assets/geo/ukraine_offline.json.gz`. APK міститиме контури вбудованими.
- **Збірка через AndroidIDE без офлайн-пакета:** при першому вході на карту з інтернетом застосунок один раз завантажує статичні GeoJSON із відкритого репозиторію, перетворює на локальну геометрію та зберігає її у приватному сховищі. Надалі масштабування й рух здійснюються офлайн. До завершення початкового імпорту карта не відображається.
- Дані адміністративних меж походять із OpenStreetMap через `darmat1/ukraine-geo-data`. Похідні дані потребують атрибуції за ODbL: https://www.openstreetmap.org/copyright. Для використання без цієї ліцензії потрібне інше легальне джерело геометрії.

### Довідник територій

Для повного списку територій при побудові на GitHub Actions виконується `scripts/prefetch_katottg.py` і в APK додається `regions_full.json`. В AndroidIDE локальний fallback містить менше населених пунктів; повний довідник завантажується при першому запуску з інтернетом. Перевіряйте актуальність КАТОТТГ при поширенні APK.

## Кастомні рофл-тривоги

Відкрийте **Налаштування → Керування тривогами та загрозами → Рофл тривоги**. У редакторі введіть назву, текст, за бажанням оберіть звук і зображення через системний файловий діалог та натисніть «Зберегти свій сценарій». Потім оберіть території, затримку і натисніть оголошення. Усі файли залишаються на пристрої. Для вже запланованих повідомлень дані не видаляються автоматично.
